# GoodVibes 3.1.1

The curl installer downloads released binaries, required runtime files, native
addons, the browser driver and WebUI from one monorepo release. It installs the
TUI, Agent and daemon commands and configures the daemon to serve the WebUI.
No Git checkout, dependency installation or source compilation is required.

The installer retains existing command paths, settings and data, upgrade/restart
handling, service migration, PATH setup and uninstall. `GOODVIBES_VERSION` pins
the entire suite; the default selects the latest published release.

Compiled TUI and Agent installations can use their normal automatic-update
paths against this monorepo's release feed. Linux runtime companions update and
roll back with their executables. Native daemon installations retain a verified
installation receipt for automatic-update ownership. Installer-owned WebUI bundles
are refreshed to match the daemon version after an automatic update; custom
bundles remain host-managed. Existing update opt-outs remain in effect.

See [installation](../installation.md) and [decision-model policies](../decision-model-policy.md).
