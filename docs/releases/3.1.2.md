# GoodVibes 3.1.2

Selected-item help now appears above continuous option lists across TUI and
Agent. Selection keeps the list stable, including settings, search results,
generic pickers, command completion, profiles and reasoning choices. Long help,
inline editing, mouse selection and confirmation prompts remain available.

Terminal settings now include decision-provider and model pickers, explicit
Default - On / Preferred / Classic - Off selection, execution-permission
selection including YOLO, fallback ordering, and Decision Router category,
provider, model and effort controls. WebUI has decision-provider and model
selection plus structured fallback editing. See the
[decision-model setup guide](../decision-model-policy.md) for the controls.

Model-catalog loading preserves the current reasoning-capability fields.
GPT-6.1 Sol supports xhigh and max without being downgraded to high. Stored effort
preferences survive model switches. Duplicate effort notices are removed, and
recoverable settings diagnostics stay inside the application's logging path
rather than appearing below the terminal footer.

Live autonomous action receipts reject a second claim while preserving both
the decision and its claim in the append-only audit history.

All suite products share version 3.1.2. Install or upgrade through the
[release installer](../installation.md) or the applications' update controls.
