# GoodVibes 3.1.3

Agent catalog routing packs complete entries into fewer source-screening
requests. Every query, candidate and evidence field remains screened, and the
canonical decision reader receives the original values. Existing input limits,
cancellation and source-change checks remain in force.

Structured source readings now reject accessor properties and proxy results
before consuming them. Both catalog and structured readings preserve the native
screening owner's bounded refusal reason and release captured sources before
reporting failure.

Generated knowledge review IDs and Git revision evidence no longer accidentally
trigger payment-card refusals during knowledge review and contract repair.
Stored Git revisions stay unchanged, and user-supplied card material is still
refused.

For installations still on 3.1.1, see the
[repository-rename migration instructions](../installation.md#existing-installations-and-services).
