# GoodVibes 3.1.4

Shift-uppercase input works again across terminal text fields. Keyboard modes
are restored correctly when opening an external editor and when exiting.

Large contract reviews keep accepting input while files are inspected. Repeated
checkpoint parsing and duplicate review evidence no longer cause the progressive
multi-second input backlog observed during concurrent work. Very large checkpoint
writes can still cause brief pauses; the sustained source-UI test measured a
45 ms p95 input-to-paint time and a 502 ms maximum across 2,343 input actions.

Planner and worker tools retain their contract's execution-mode context until
the work drains. This fixes delayed read/find calls failing with
"Execution mode is no longer current" after the admitting invocation finishes.
Cancellation and owner-policy changes still stop work.

Verification preserves complete review evidence in smaller requests. If the
configured decision models cannot complete verification, the contract stops and
retains its candidate output instead of restarting the same failing checks.
