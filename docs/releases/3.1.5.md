# GoodVibes 3.1.5

Contract planning starts with a complete directory-based filename catalog.
Review catalogs preserve every captured path, including dotfiles and files
without extensions. Source contents and symbols are read as needed, reducing
initial planning overhead in large repositories.

Plan repairs focus on the listed problems while retaining the previous plan and
original requirements. Full repository maps and review catalogs are no longer
resubmitted with every repair.

Planning stops with a diagnostic when repairs repeat the same unresolved state.
A native plan returned for revision must change before it can be considered
again, preventing repeated acceptance decisions on an unchanged proposal.

Active planner agent IDs are saved immediately, so checkpoints include the
planner currently running. Cancellation waits for its admitted work and cleanup
to drain.
