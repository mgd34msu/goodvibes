# GoodVibes 3.1.6

Contract workers searching large projects spend less time repeatedly validating
the same permission owner for every file and previously read path. Read-only
searches reuse completed checks for short intervals, reducing the overhead that
caused concurrent workers to appear stalled. Cancellation remains checked at
every checkpoint, and complete validation runs before results are returned.

Tool calls running longer than a minute show their elapsed time on the agent's
progress line and produce diagnostic log notices.
