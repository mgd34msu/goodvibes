# GoodVibes 3.3.3

GoodVibes 3.3.3 makes the settings screen shorter to read and quicker to open.
Nothing you have stored changes, and an installed 3.3.2 updates to it as usual.

## Settings

- **Each setting is one line.** A row is the setting's name and its value in
  words; the section and key that were printed under each name are gone, in
  the terminal app and the Agent alike. Typing still searches every setting by
  name, key and description, so a key still finds its setting.
- **Choosing `Open settings…` opens the settings screen at once,** at the
  first topic, with no form asking where first. Typing `/settings open <where>`
  (a topic, a section, a key or words to search for) still opens it there.

## For client authors

- **Knowledge reports when its background readings are done.**
  `KnowledgeService.scopeReadingsSettled()` resolves once no ordinary-view
  reading is queued or running for the store, at once when none is. A view
  still never waits on them.
