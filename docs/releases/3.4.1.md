# GoodVibes 3.4.1

GoodVibes 3.4.1 makes one change: the start screen of the terminal app and the
Agent no longer shows suggested prompts. Nothing you have stored changes, and an
installed 3.4.0 updates to it as usual.

## The start screen

- **The "Try one of these" suggestions under the logo are gone.** The three
  prompts that were offered for the working folder are no longer drawn, in the
  terminal app and the Agent alike. Tab in an empty composer and a click on a
  suggestion no longer put one in the composer; Tab does what it does
  everywhere else. Nothing else on the screen moved: the logo, the model and
  folder lines and the key hints are where they were.

## For client authors

- **The `terminal-shell/first-run` subpath no longer exports the starting
  prompts.** Removed: `starterPrompts`, `starterPromptsFor`,
  `readFolderFacts`, the type `FolderFacts`, `takeNextStarterPrompt`,
  `starterPromptAtRow` and `fillComposerWithStarterPrompt`.
  `installSplashAdditions` no longer takes `workingDirectory` or
  `fillComposer`, and `SplashAdditionsView` no longer has `folder` or
  `prompts`.
