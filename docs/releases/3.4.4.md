# GoodVibes 3.4.4

GoodVibes 3.4.4 keeps what you pasted. A message brought back from the input
history now comes back with its pasted text, in the same run and after a
restart, in the terminal app and in the Agent. An ordinary message costs what
it cost before.

## Upgrading

- **Lines saved by 3.4.3 and earlier stay placeholders.** Those releases saved
  a long paste in the history as its placeholder alone (`[TEXT: p1, 40
  lines]`); the text itself was never saved, so it cannot come back. Such a
  line still loads and is shown, and sent, as the plain text it is.
- **After a return to 3.4.3**, the history still loads: lines saved by 3.4.4
  show their placeholders, and the folder that holds their pasted text is left
  alone.

## Input history

- **A recalled message comes back as you sent it.** Up, Down and history
  search (`Ctrl+R`) put the message back in the composer with each long paste
  folded as its shortcut, `[TEXT: pN, M lines]`, holding its whole text:
  `/paste list` shows it, you can type around it, and `Enter` sends the full
  text. Before, the same run brought the text back unfolded into the composer,
  and the next start brought back only the placeholder, which was then sent as
  it was.
- **Pasted images come back too,** as their marker holding the image, for the
  rest of the run. They are not written to disk.
- **An old placeholder can no longer pick up another paste's text.** A
  placeholder recalled after a restart named a paste number (`p1`) that the
  new run could be using for a different paste, and was sent with that paste's
  text. A message now leaves nothing of its pastes behind when it is sent.
- **Where pasted text is kept.** The history list (`~/.goodvibes/tui/input-history.json`,
  `~/.goodvibes/agent/input-history.json`) stays the small list of lines as
  typed; a fold's placeholder names its content key. Each pasted text is a file
  of its own beside it, `input-history-pastes/<key>.txt`, readable by you
  only, with the same secret redaction as the typed lines. It is written once,
  when the message that first holds it is sent, and read only when a line that
  names it is recalled. A message with no new paste writes the list alone, as
  before.
- **How much is kept.** The history keeps its 500 lines. Pasted text is kept up
  to 8 MiB in all, counted from the newest line, and stored once however many
  lines name it. A paste file is removed when no kept line names it any more
  (its line dropped past 500, or older text past 8 MiB); that line then comes
  back as its placeholder.
- `@path` and `!@path` in a recalled message are read again when it is sent,
  so the file is sent as it is now.
