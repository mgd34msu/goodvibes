# GoodVibes 3.6.2

Patch release fixing OAuth subscription token-revision recovery across daemon restarts.

## Fixed

### OAuth subscription token-revision crash recovery
- When a daemon restart or crash interrupted an OAuth token refresh after writing a newer `tokenRevision` to the secret store (`GOODVIBES_SUBSCRIPTION_TOKENS_<PROVIDER>`) and a subsequent refresh evicted the previous revision before `shared/subscriptions.json` updated `tokenRevision`, `SubscriptionManager.withTokens()` previously returned `null` and treated a live subscription as signed out (`"No model is set up yet."`).
- `SubscriptionManager.withTokens()` now recovers the newer persisted token revision when `secret.revision > record.tokenRevision`, and `claimIn()` advances `tokenRevision` in `subscriptions.json` under the store lock so subsequent refreshes compare and commit cleanly.
