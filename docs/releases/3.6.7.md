## Fixed

### Calibrate native contract disposition instructions (`contract.native.*`)
- Updated `INSTRUCTIONS` in `platform/contract/native-decisions.ts` to match the permissive host-verified framing used by `AUTONOMOUS_TOOL_INSTRUCTIONS`: informing the decision model that host authority, workspace scope, immutable root criteria, remaining budgets, and structural/unit checks (when `evidence.problems` is empty or absent) are already verified, so ordinary valid contract plans, fix groups, bounded corrections, and passing attempt selections clear the high-stakes `act` band (`confidence >= 0.85`) while harmful, off-task, or invalid operations continue to be rejected at high confidence.
