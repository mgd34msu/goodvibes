# Test risks

Every test in this repository proves one risk, and every case has a row here. A new proof adds its rows in the same change; the runner refuses a case with no row, a row that names a case its file does not have, and a file whose `// Proves:` lines are not the risks of its rows. The risk of a row is, word for word, a `// Proves:` line in the header of the file that holds the case.

Columns: the area; the risk; the file, from the repository root; the case title as it reads (a template title with its `${...}` as written, `|` written `\|`); the breakage that turns the case red.
