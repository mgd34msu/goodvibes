# Old planning records

Earlier versions kept a project's planning (its goal, questions, decisions and tasks) as planning records. That planning interview is retired. At the first start of this version the daemon carries those records into Work by itself, nothing dropped, and says once how many pieces of work it carried (a record it could not carry is said in one line and tried again at the next start). Work carried in from those records is kept by the daemon as history: the Work place's History list shows each piece with what it asked for and what done meant, in the terminal app, the Agent and the web UI. It never runs by itself, and it grants no approval to start anything.

The records themselves are left where they were, so a return to an earlier version still reads them.
