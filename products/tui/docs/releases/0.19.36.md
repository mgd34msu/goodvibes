# GoodVibes TUI 0.19.36

## Changes

- Updated `@goodvibes-jev/engine/platform` to `0.25.13`.
- Added Home Assistant remote-session idle TTL wiring for `surfaces.homeassistant.remoteSessionTtlMs` in onboarding and Settings > Surfaces.
- Documented the platform-owned Home Assistant Assist conversation routes:
  `GET /api/homeassistant/health`,
  `POST /api/homeassistant/conversation`,
  `POST /api/homeassistant/conversation/stream`, and
  `POST /api/homeassistant/conversation/cancel`.
- Regenerated foundation operator contract artifacts from the platform 0.25.13 contract.

## Notes

Home Assistant remains opt-in. The TUI owns setup and credential entry; the platform daemon owns Home Assistant API calls, direct non-WRFC conversation execution, final-event correlation, and event delivery.
