# GoodVibes TUI 0.19.39

## Changes

- Updated `@goodvibes-jev/engine/platform` to `0.25.16`.
- Picked up platform Cloudflare operational-token creation fixes for documented permission names, `Write`/`Edit` variants, and account/zone resource scoping.

## Notes

No TUI route contract changed in this release. Existing Cloudflare onboarding and `/cloudflare` flows continue to call the platform daemon APIs; the platform now creates operational tokens more reliably for Queues, Secrets Store, R2, DNS, and Zero Trust Access selections.
