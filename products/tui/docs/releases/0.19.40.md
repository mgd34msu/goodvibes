# GoodVibes TUI 0.19.40

## Changes

- Updated `@goodvibes-jev/engine/platform` to `0.25.17`.
- Picked up platform Cloudflare operational-token policy fixes for separate account, zone, and R2-bucket resource scopes.
- Picked up platform verification that fails token creation with `CLOUDFLARE_TOKEN_POLICY_MISMATCH` instead of storing an unusable Cloudflare token when Cloudflare does not persist expected policies.

## Notes

No TUI route contract changed in this release. Existing Cloudflare onboarding and `/cloudflare` flows continue to call the platform daemon APIs; the platform now prevents storing Cloudflare operational tokens that appear in the dashboard with missing permissions or resources.
