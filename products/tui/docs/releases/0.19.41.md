# GoodVibes TUI 0.19.41

## Changes

- Updated `@goodvibes-jev/engine/platform` to `0.25.18`.
- Picked up platform Cloudflare provisioning idempotency across repeated onboarding runs.
- Picked up platform recovery for exists/quota-style Cloudflare create errors, including Secrets Store `maximum_stores_exceeded` handling when an existing usable store is visible.

## Notes

No TUI route contract changed in this release. Existing Cloudflare onboarding and `/cloudflare` flows continue to call the platform daemon APIs; the platform now more reliably reuses existing Cloudflare resources instead of failing or duplicating them on repeated setup runs.
